# Student Planner

Petit projet React volontairement très simple pour pratiquer Git et GitHub.

## Installation

Prérequis : Node.js 20.19 ou plus récent (`node -v`).

```bash
npm install
npm run dev
```

## Objectif

Le projet est fait pour être modifié pendant les exercices :

- changer le titre ;
- modifier le header ;
- ajouter un footer ;
- modifier une carte ;
- créer des branches `feature/...` ;
- faire des commits ;
- créer des Pull Requests ;
- provoquer et résoudre un conflit.
